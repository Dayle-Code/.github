# Dayle Code

Somos un equipo de desarrollo que convierte ideas en soluciones digitales reales.

Creamos sitios, sistemas y herramientas web para personas, comercios y equipos que quieren ordenar procesos, vender mejor o llevar su negocio al mundo digital.

## Qué hacemos

- Landing pages y sitios institucionales.
- Catálogos digitales.
- Web apps y sistemas internos.
- Dashboards y MVPs.
- Automatizaciones e integraciones.
- Sistemas de pedidos.
- Mantenimiento, soporte, deploy y hosting.

## Cómo trabajamos

Nos enfocamos en entender el problema antes de programar. Buscamos soluciones claras, útiles y mantenibles, explicando lo técnico en lenguaje común y acompañando al cliente durante el proceso.

## Tecnología

Trabajamos con herramientas como Django, PostgreSQL, Docker, React, Tailwind CSS, Bootstrap y Astro, eligiendo cada stack según la necesidad real del proyecto.
